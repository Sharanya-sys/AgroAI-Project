🧠 DISEASE DETECTION SYSTEM

Supported Diseases (triggered by filename):

1. Tomato Early Blight (filename contains "tomato")
   • Cause: Fungal infection (Alternaria solani)
   • Symptoms: Dark brown spots with concentric rings
   • Severity: 🔴 HIGH RISK
   • Confidence: 92%

2. Leaf Spot Disease (filename contains "leaf")
   • Cause: Bacteria/fungus
   • Symptoms: Yellow/brown spots with halos
   • Severity: 🟡 MEDIUM RISK
   • Confidence: 88%

3. Rust Disease (filename contains "rust")
   • Cause: Fungal spores
   • Symptoms: Orange powder-like spots
   • Severity: 🔴 HIGH RISK
   • Confidence: 90%

4. Healthy Plant (filename contains "healthy")
   • No disease detected
   • Severity: 🟢 HEALTHY
   • Confidence: 95%

5. Unknown (filename doesn't match above)
   • Unable to identify
   • Severity: ⚠️ UNKNOWN
   • Confidence: 45%

🔧 BACKEND ROUTES

Route: GET /
Purpose: Serve home page with sidebar and upload interface
Returns: index.html with full dashboard

Route: POST /predict
Purpose: Handle image upload and disease prediction
Parameters: file (image upload)
Returns: result.html with prediction details

Route: GET /api/weather
Purpose: Fetch current weather data
Returns: JSON with temperature, weather, humidity, location
Note: Uses free Open-Meteo API (no key required)
