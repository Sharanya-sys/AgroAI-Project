 USAGE INSTRUCTIONS

Step 1: Start the Server
  The server is already running at http://127.0.0.1:5000

Step 2: Open Your Browser
  Go to: http://127.0.0.1:5000

Step 3: Explore the Dashboard
  • Read the header information
  • Check the weather widget
  • Review usage tips
  • Change language (optional)

Step 4: Upload an Image
  • Use drag & drop OR click to browse
  • Choose a test image with disease keyword:
    - tomato.jpg → Tomato Early Blight
    - leaf.jpg → Leaf Spot Disease
    - rust.jpg → Rust Disease
    - healthy.jpg → Healthy Plant

Step 5: Analyze
  • Click "Analyze Plant" button
  • Wait for result page to load

Step 6: View Results
  • See disease name and severity
  • Read cause and symptoms
  • Check prevention tips
  • Apply treatment suggestions

Step 7: Try More Features
  
  • Check weather
  • Read tips
  • View about section
  • Upload another image
